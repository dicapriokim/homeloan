# 🏠 주택 자금 조달 & 정책모기지 실전 시뮬레이터 (Home Fund Simulator)

> **2026년 9월 현행 금융 및 주택 정책 규정 완벽 반영**  
> 기축 아파트 매매, 신축 아파트 청약·분양, 전세자금대출 및 정부 정책모기지(디딤돌·보금자리론·신혼/청년 버팀목) 실시간 적격성 심사 통합 솔루션

---

## 📌 개요

**Home Fund Simulator**는 무주택 실수요자, 신혼부부, 1인 단독 세대주가 내 집 마련 또는 전세 계약을 진행할 때 발생하는 복잡한 자금 조달 구조, 대출 한도 규제(LTV/DSR), 법정 필수 부대비용 및 입주 비용을 한눈에 시뮬레이션하고 최적의 금융 플랜을 수립할 수 있도록 설계된 전문 웹 애플리케이션입니다.

## ✨ 핵심 기능

### 1. 3대 핵심 시뮬레이션 모드
- **구축·기축 아파트 매매 모드**:
  - 매매가 및 보유 자기자본(순자산) 기반 필요 대출금, LTV(생애최초 80%, 일반 70%), DSR 40% 자동 산출.
  - 법정 필수 취득비용(취득세, 중개보수, 등기비, 인지세 등)과 선택적 입주·수리비(인테리어, 이사비)를 분리하여 순수 취득 최소 필요 자금과 최종 예산을 동시 도출.
- **신축 아파트 청약·분양 4단계 실전 로드맵**:
  - `1단계 계약금 납부(10%)` ➔ `2단계 중도금 집단대출(60%)` ➔ `3단계 잔금일 일괄 대환 정산(전세금 회수 + 잔금 주담대 + 계약금 신용대출 전액 상환)` ➔ `4단계 입주 후 월 원리금 안착`의 타임라인 및 자금 흐름 시뮬레이션.
- **전세자금대출 모드**:
  - 목표 전세보증금 및 보유 현금 기반 필요 전세대출금, 월 이자액, 보증금 반환보증료 정밀 계산.
  - 가구 조건에 맞춘 청년 버팀목(연 2.1%), 신혼 버팀목(연 2.4%), HUG 안심전세(연 3.6%), 1금융 시중 전세대출(연 4.1%) 자동 판정.

### 2. [👥 가구 조건·심사] 독립 진단 센터 및 5대 핵심 프로필
- **5대 핵심 가구 프로필 원클릭 프리셋**:
  1. `💑 기본 맞벌이 (7.7천)`: 결혼 7년 이상, 부부합산 7,700만 원 ➔ 시중은행 주담대 4.2% 적격
  2. `💡 외벌이 전략 (5.1천)`: 서류상 외벌이 5,120만 원 ➔ 디딤돌 3.0% 승인 (30년 총이자 약 5,100만 원 순절감)
  3. `👶 1자녀 보금자리 (7.7천)`: 미성년 1자녀 소득 완화 특례 통과 ➔ 보금자리론 3.8% 고정금리 적격
  4. `💍 신혼부부 7년이내 (7.5천)`: 혼인 7년 이내 신혼부부 ➔ 디딤돌 3.0% / 신혼 버팀목 2.4% 적격
  5. `👤 1인 단독 세대주 (5.0천)`: 1인 세대주 단독 심사 ➔ 보금자리론 3.8% [단독신청] / 청년 버팀목 2.1% 적격
- **실시간 4대 대출 상품 적격성 종합 판정**:
  - 디딤돌, 보금자리론, 시중은행 일반 주담대, 전세 버팀목의 자격 요건(소득 한도, 주택 가격 한도, 보증금 한도)을 실시간 검증하고 승인 적격/부적격 사유 표출.

### 3. 직관적인 대시보드 & 마크다운 리포트 생성
- 실시간 계산 결과 카드(필요 대출금, 월 원리금, 실수령액 대비 주거비 비율, 잔여 여유 자금).
- 대출 조건별(만기 30년/40년/50년, 금리별) 상환액 비교 매트릭스.
- 보고용 마크다운(.md) 리포트 즉각 복사 및 내려받기 지원.

## 🚀 최신 업데이트 내역 (v2.7.0)

### 1. 필수(취득세·거래비용) 토글 연동 및 자금조달 구조표 고도화
- **자유로운 비용 항목 토글**: 사용자가 법정 필수 비용(취득세, 중개보수 등) 및 선택적 비용(인테리어, 이사비)을 각각 독립적으로 포함/제외할 수 있도록 체크박스 연동 지원.
- **대출금 산식 원칙 고정 (`대출금 = 집값 - 순자산`)**: 부대비용 포함 여부에 상관없이 은행 대출 규정(LTV/DSR 기준 담보평가액)에 따라 순수 주택 매매가/분양가/전세보증금에서 보유 현금을 차감하는 정석 산식을 견고하게 유지.
- **`[준비해야 할 부가 비용]` 행 신설**: 체크박스 선택에 따라 별도로 마련해야 하는 현금(필수 비용 + 선택 비용)을 명확한 별도 행으로 표기하여 대출 외 실부담 현금 규모를 한눈에 파악 가능.
- **4가지 상태별 `[소계]` 및 `[총계]` 정밀 라벨 분기**:
  1. `필수(O) + 선택(X)`: `➔ [소계] 순수 취득/분양/전세 필요 자금` (기본 집값 + 법정 필수비용)
  2. `필수(O) + 선택(O)`: `➔ [총계] 최종 입주 총 소요 예산` (집값 + 법정 필수비용 + 입주·수리비 합산)
  3. `필수(X) + 선택(X)`: 기본 취득/분양가/전세보증금 순수 표기
  4. `필수(X) + 선택(O)`: `➔ [소계] 선택적 비용 포함시 예산` (집값 + 선택적 입주·수리비 합산)

### 2. UI 시인성 강화 및 은행 현장 실무 D-Day 타임라인 반영
- **월 상환액 구분선 CSS 강화**: HTML table `border-collapse` 환경에서 발생하던 테두리 실선 누락 현상을 해결하고, `border-t-2 border-slate-400`를 셀 단위로 적용하여 금융 산출물 간 시각적 구분감 극대화.
- **실무 팩트 기반 대출 신청 D-Day 타임라인 고도화**:
  - **정부 정책대출 (디딤돌·보금자리·버팀목)**: 기금e든든/HF 비대면 사전자산심사(1~2주)와 수탁은행 본심사(2~3주) 소요 기간을 감안하여 **잔금 D-40~60일 전(1.5~2개월 전)** 사전 접수 권장 체계 구축.
  - **시중은행 일반 주담대/전세대출**: 계약 직후 **잔금 D-30일 전** 정식 접수 가이드 분기.

### 3. 마크다운 보고서(mdGenerator.js) 3대 탭(매매/분양/전세) 전반 완벽 동기화
- 웹 대시보드에서 계산된 자금조달 구조(부가 비용 분리, 소계/총계 라벨, 대출 신청 타임라인)가 내려받기 및 클립보드 복사용 마크다운 리포트에도 100% 동일하게 반영되도록 전면 동기화.

### [v2.6.0] 윤년 및 실제 일수(Actual Days) 기반 월별 이자 정밀 보정
- **HF 및 시중은행 일할 계산 방식 적용**: 단순 `연이자 / 12` 방식에서 탈피하여, 해당 월의 실제 일수(28일~31일)를 반영하여 월별 이자를 정밀하게 계산.
- **한국식 윤년 보정 로직 (Leap Year Correction)**: 한국 주담대 이자 계산 관행에 맞춰 윤년(366일) 여부를 정확히 판단하고 일할 이자율을 동적으로 보정하여 실제와 동일한 납입 스케줄 도출.
- **스크롤 컨트롤러 (Scroll Controller UI) 도입**: 모바일 및 데스크톱 환경에서 가구 조건과 금리 선택부를 더 직관적으로 접근할 수 있도록 동적 스크롤 컨트롤러 UI 탑재.

### [v2.5.0] 1인 단독 세대주 보금자리론 [단독신청] 분기 및 8대 논리 오류 개선
- **팩트 기반 규정 준수**: 한국주택금융공사(HF) 현행 기준에 따라, 보금자리론은 기혼 부부뿐만 아니라 **1인 단독 세대주(연소득 7,000만 원 이하, 담보평가액 6억 원 이하)**도 차주 단독 명의로 신청 가능합니다.
- **가구 형태 보존**: 단독 세대주 모드에서 보금자리론(연 3.8%) 선택 시 가구 형태가 `기혼(부부합산)`으로 강제 전환되거나 시중은행(4.2%)으로 이탈하지 않고 `👤 세대주 혼자 (1인)` 상태를 온전히 보존합니다.
- **상황 인지형 UI 뱃지**: 금리 프리셋 라디오 뱃지를 기혼 시 `[부부합산]`, 1인 단독 세대주 모드일 때는 `[단독신청]`으로 자동 분기 표기합니다.
- **소득 심사 가이드 정밀화**: 차주 단독 심사(보금자리론 / 시중 주담대 / 청년버팀목) 규정을 안내 가이드 및 마크다운 리포트에 명문화하였습니다.

### 2. 8대 핵심 논리 오류 및 하드코딩 전면 개선
1. **모드 전환 시 사용자 선택 금리 영구 보존**: 매매/분양 탭 전환 시 4.2%로 무조건 리셋되던 하드코딩을 제거하여 사용자 선택 금리(디딤돌 3.0%, 보금자리 3.8% 등) 영구 보존.
2. **전세 버팀목(신혼 2.4% / 청년 2.1%) 최적 금리 실시간 연동**: 가구 조건에 맞춘 최적 금리 자동 계산 및 진단 센터 4번째 버팀목 카드로 즉각 적용.
3. **가구 조건 5대 사전 설정 프로필 카드 레이아웃 복구**: 카드 클릭 시 `flex-col` 구조를 유지하여 수직 비율 및 배지 왜곡 버그 해결.
4. **소득 형태 빠른 선택(맞벌이/외벌이) 2분할 재편**: 직관적인 2버튼 트랙 세그먼트 UI로 일체화.
5. **부적격 대출 상품 무의미 선택 원천 차단**: 심사 탈락 상품은 라디오 버튼 비활성화(`disabled`), `[신청불가]` 뱃지, 취소선, 안내 토스트를 부여하고 승인 적격 상품으로 안전 자동 전환(Auto-Fallback).
6. **1인 단독 보금자리 단독신청 정합성 확보**: 단독 세대주 자격 심사 및 단독 모기지 시뮬레이션 완벽 지원.
7. **진단 카드 클릭 시 목적지 화면 정밀 라우팅**: 구입자금 대출은 매매/분양으로, 전세자금 대출은 전세대출 시뮬레이터로 안전 라우팅.
8. **2026년 9월 현행 정책 규정 일체화**: HF 보금자리론 소득 요건(기본 7천, 신혼 8.5천, 1자녀 9천, 다자녀 1억) 및 HUG 디딤돌(일반 5억 이하, 신혼/2자녀 6억 이하) 최신 기준 일체화.

## 🛠️ 기술 스택 및 구조

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, Lucide Icons
- **Backend / Server**: Node.js, Express (정적 웹 및 로컬 호스팅 지원)
- **Architecture**:
  ```text
  home/
  ├── public/
  │   ├── index.html              # 반응형 메인 UI (사이드바, 시뮬레이터, 가구조건, 금리표)
  │   ├── css/
  │   │   └── styles.css          # 커스텀 스타일 및 애니메이션
  │   └── js/
  │       ├── app.js              # 메인 UI 상태 관리, 오토 폴백, 이벤트 컨트롤러
  │       ├── mdGenerator.js      # 마크다운 보고서 자동 생성 엔진
  │       ├── calculator/
  │       │   ├── loanCalculator.js    # LTV, DSR, 원리금균등, 원금균등, 만기일시 상환 연산
  │       │   ├── taxCalculator.js     # 취득세, 지방교육세, 중개보수, 보증료 세제 연산
  │       │   └── scenarioEngine.js    # 매매/분양/전세 시나리오 및 타임라인 생성
  │       └── data/
  │           └── interestRates.js     # 2026년 9월 기준 정책모기지 금리/심사 데이터셋
  ├── document/                   # 주택 대출 심사 기준 가이드 문서 (V1 ~ V5)
  ├── server.js                   # Node.js Express 로컬 웹 서버
  ├── package.json
  └── README.md
  ```

## 💻 실행 방법

### 로컬 Node.js 서버 실행
```bash
# 의존성 패키지 설치
npm install

# 서버 실행 (기본 포트 3000)
npm start
```
웹 브라우저를 열고 `http://localhost:3000`에 접속합니다.

### 정적 파일 직접 실행
별도의 Node.js 설치 없이 `public/index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 직접 열어도 모든 시뮬레이션 기능이 100% 정상 작동합니다.
